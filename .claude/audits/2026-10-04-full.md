## Architecture and contracts

The current workspace has 15 Rust crates (including three protocol drivers) plus `apps/desktop`. Domain vocabulary and the policy gate belong to `oxyn-core`; query classification to `oxyn-query`; execution, session ownership, approvals, streaming and cancellation to `oxyn-exec`; Arrow buffers/export to `oxyn-data`; local SQLite persistence to `oxyn-store`; keychain access to `oxyn-secrets`. Driver traits and catalog models isolate SQLite, PostgreSQL and MySQL/MariaDB adapters. `oxyn-ai` constructs tier-filtered prompts and agent commands; `oxyn-llm` owns provider transports. Plugin hosting remains partly deferred. `oxyn-desktop` assembles these services and is the sole Tauri-dependent crate.

The principal application path is React action → typed IPC client → Tauri command → Backend → Command/PolicyGate → executor/session → driver → events/result pages/history → React state. Agent execution joins the same bus as `Actor::Agent`. Updater/menu/window plumbing has documented exceptions because it does not execute database commands. Native confirmation and per-window ownership are additional host boundaries, not guarantees provided by React dialogs alone.

Authority reviewed included CLAUDE, README, `.agents/README`, audit/review/security procedures and applicable rules, implementation-plan current sections and historical qualifications, architecture, security, UX, performance, driver/AI/plugin contracts, release instructions, manifests/lockfiles, build/test/lint/CI/Tauri/capability configuration. `SECURITY.md` and `PERFORMANCE.md` are under `docs/`, not the root. Relevant ADRs included 0002–0006, 0012–0017, 0021, 0024, 0026–0034, 0037, 0039–0043, 0045–0046 and 0048–0053.

Historical GPUI measurements and completed GPUI flows were not treated as evidence about the current Tauri application. Superseded and subsequently qualified contracts were checked: notably ADR-0040 permits a bounded exit despite a missing draft acknowledgement, so that alone is not refiled as #29.

## Important hypotheses disproved or rejected

- A foreign window's transaction being controlled through the normal exit route: session ownership and per-window grouping prevent it. F02 acts on legitimate owned sessions after consent is cancelled.
- Old global event/subscription theft: current generations and WindowKey-scoped subscriptions address that original cause.
- A provider redirect/proxy trivially crossing Local reach: current shared transport disables redirects/proxies and filters resolved addresses; no new bypass established.
- Result export immediately truncating an existing destination: current temporary-file/publish flow addresses #23; no regression demonstrated.
- Production agent transaction commands passing unchanged: existing transaction-control refusal remains; C02 concerns human commands receiving inappropriate read-only bounding.
- The CI dependency check still silently skipping cargo-deny: the workflow now installs a pinned, checksummed binary and CI missing-tool mode fails. #155/#159 were not refiled.
- Release reruns overwriting published assets: script checks draft status around uploads and does not clobber; the documented single-upload publication race is not a newly discovered defect.
- Required qualite/administrator bypass mismatch: the dated ADR explicitly records the maintainer-approved administrator bypass. It is an intentional governance choice, not a repeated #160 finding.
- Missing complete WASM execution: deferred phase 4, not a shipped feature defect.
- Unlimited audit/egress storage as an accidental leak: append-only retention is explicitly decided; revisit as a design risk, not an invented current requirement.
- Every unmeasured performance budget being exceeded: unsupported. No frame/RSS overrun is claimed.

## Meaningful regression-test gaps

1. Registry tests choose artificially unique keys instead of composing two production workspace managers.
2. Exit cancellation tests use one transaction and assert only that exit stops, missing later SQL submissions.
3. Agent keychain tests verify persistence and launch injection without verifying reuse invalidation after a secret-only edit.
4. Log tests fabricate already-known SQLx/ACP targets instead of running the real SQL classifier under the production host layer.
5. SQLite driver cancellation verdicts need post-operation database-state assertions, not only cancelled futures.
6. MySQL transaction tests need the executor's production read-only bound, not only writable Local driver requests.
7. JSON export round-trips need duplicate column names from joins as well as all-null columns.
8. Updater state tests must agree with the displayed off-switch contract and cover late completions; file tests must overlap setters.

The server-dependent ignored tests remain meaningful validation gaps in the default gate; their presence is not itself filed as a generic missing-tests issue. The new issues name the exact production invariants their regression tests must protect.

## Architecture observations

**Actual bugs** are the nine findings above. They cluster around composed ownership/lifecycle invariants: workspace-local identity escaping to a global registry, an old async continuation surviving cancellation, a new secret-storage representation omitted from a cache identity, policy bounds conflating read SQL with transaction control, and state persistence/publication split across locks.

**Design risks** kept separate: keychain and SQLite cannot be one transaction, append-only audit growth is deliberate, and stopping a write requires a driver-specific outcome rather than a generic future drop. Existing mitigations and documented tradeoffs must be retained while fixing defects.

**Future maintenance recommendations**, without additional issues: document identity scope on every shared registry; make cancellation generations part of multi-step workflows; centralize complete launch identity; add contract tests at real subsystem compositions. The architecture and plan contain dated single-window/proposed wording alongside delivered multi-window behavior; realign these descriptions without treating historical text as current guarantees. No broad rewrite is prescribed.
