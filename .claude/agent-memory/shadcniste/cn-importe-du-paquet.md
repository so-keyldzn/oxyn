description: Files generated by the CLI import `cn` from the `cn` package, not from the alias; switching to `@/lib/utils` is mécanique but never touches ui/
metadata:
  type: feedback
---

`grep 'from "cn"'` returns ~80 files, including **all of `src/components/ui`**:
the CLI writes the package import and not the `utils` alias of
`components.json`, and the example in `styling.md` does the same. `@/lib/utils`
only re-exports `cn`: replacing the import in an Oxyn file changes nothing at
runtime.

**Why:** found on 2026-09-23; without this context, the pattern is taken for a
single file's drift, or one is tempted to "fix" `ui/` too.

**How to apply:** fix as `mécanique` in `src/components/oxyn` and
`src/features` (import placed after the other `@/lib/…`, `import/order` is
disabled); never touch `ui/`, which the next `add` would rewrite. See
[[cn-supprime-les-tailles-de-theme]] (memory of `frontiste`).
